# Learning Local Binary Patterns via Straight-Through Estimation

Texture classification is a core task in computer vision, with applications ranging from industrial surface inspection to medical image analysis. For over two decades, **Local Binary Patterns (LBP)** have served as one of the most practical and efficient feature descriptors for texture analysis. 

The classical LBP operator operates on a simple local comparison rule. At each pixel location in a grayscale image, the operator samples $P$ neighboring points lying on a circle of radius $R$ centered at the pixel. It compares the intensity of each neighbor $I_p$ against the intensity of the central pixel $I_c$. If the neighbor intensity is greater than or equal to the center, it produces a binary bit `1`; otherwise, it yields `0`. Concatenating these $P$ comparisons forms a $P$-bit binary code. Computing the histogram of these binary codes across an image region produces a 256-bin feature vector (for $P = 8$) that describes the local micro-texture distribution.

Despite its low computational cost and invariance to monotonic illumination changes, classical LBP has a fundamental limitation: its geometric sampling layout is fixed by hand. Standard implementations fix sampling locations to rigid circles of integer or fractional radii (such as $R = 1.0$ or $R = 2.0$) and set comparison thresholds strictly to zero. Real-world texture patterns—such as directional wood grain, woven fabrics, or anisotropic cellular structures—rarely match isotropic circular geometries. Manual tuning of sampling radii, angles, and thresholds for each new dataset is tedious and sub-optimal.

To address this limitation, Mohamed Alimoussa and Amal El Kaid (2026) introduced **FLEX-LBP**, a method that learns sampling spatial offsets and comparison thresholds directly from data using gradient descent. Because the step function used to extract binary bits has zero derivative almost everywhere, standard backpropagation cannot pass through the hard thresholds. FLEX-LBP solves this by utilizing a **Straight-Through Estimator (STE)**. During the forward pass, the model computes exact hard binary codes and precise histogram counts. During the backward pass, it approximates the step function derivative using a continuous sigmoid activation, allowing gradients to update spatial sampling coordinates and thresholds.

This article implements FLEX-LBP in PyTorch, evaluates it on a controlled synthetic texture benchmark, and compares its accuracy, cross-entropy loss, parameter efficiency, and inference speed against classical fixed LBP descriptors.

## The question(s)

This experiment answers the following primary question:

1. Can backpropagating through exact binary codes via a straight-through estimator discover better sampling geometries than fixed circular LBP, and does it improve classification accuracy?

Additionally, we investigate:

2. How does learning sampling offsets versus learning comparison thresholds independently affect model confidence and cross-entropy loss?
3. Does enabling learnable sampling offsets introduce any computational latency penalty during inference compared to standard fixed LBP descriptors?

## Setup

**The Dataset.** We construct a synthetic texture benchmark comprising six distinct visual classes designed to test spatial frequency, directionality, non-circular geometry, and noise robustness:

- **Class 0 (Horiz):** Horizontal sinusoidal grating with random spatial frequency ($3.0$ to $5.0$ cycles) and phase shift.
- **Class 1 (Vert):** Vertical sinusoidal grating with random spatial frequency ($3.0$ to $5.0$ cycles) and phase shift.
- **Class 2 (Diag):** Diagonal sinusoidal grating oriented at 45 degrees.
- **Class 3 (Check):** High-contrast checkerboard pattern generated by bi-level thresholded orthogonal sine waves.
- **Class 4 (Blobs):** Random spatial fields populated with 15 to 25 anisotropic 2D Gaussian blobs.
- **Class 5 (PinkN):** Synthetic pink noise ($1/f^{0.8}$ power spectrum density) synthesized via 2D Fast Fourier Transform filtering.

Each sample is rendered at a resolution of $48 \times 48$ pixels with additive zero-mean Gaussian noise ($\sigma = 0.08$) and normalized to zero mean and unit variance. The dataset contains 100 images per class (600 images total), split into 360 training images and 240 testing images.

**The Models.** We evaluate six descriptor configurations paired with a linear classification layer mapping histogram features to 6 class logits:

1. **Fixed LBP ($R=1.0$):** 8 sampling points fixed at radius $R=1.0$, thresholds frozen at $0.0$.
2. **Fixed LBP ($R=2.0$):** 8 sampling points fixed at radius $R=2.0$, thresholds frozen at $0.0$.
3. **Fixed Multiscale LBP ($R=1+2$):** Concatenation of histograms from fixed $R=1.0$ and $R=2.0$ (512 dimensions total).
4. **FLEX-LBP (Offsets Only):** 8 sampling points initialized at $R=1.5$, offsets optimized via STE, thresholds frozen at $0.0$.
5. **FLEX-LBP (Thresholds Only):** 8 sampling points frozen at $R=1.5$, 8 comparison thresholds optimized via STE.
6. **FLEX-LBP (Full):** 8 sampling points initialized at $R=1.5$, both offsets (16 parameters) and thresholds (8 parameters) optimized simultaneously.

**Optimization.** Models are trained for 45 epochs using the Adam optimizer with a learning rate of $0.03$ for learnable LBP extractor parameters and $0.015$ for the linear classifier. All random seeds are fixed to 42.

## The code

The core component of FLEX-LBP is the differentiable feature extraction module. It uses `torch.nn.functional.grid_sample` with bilinear interpolation to sample spatial locations at non-integer pixel offsets $(dx_p, dy_p)$ relative to the central pixel grid. The binary bit computation uses STE to pass gradients during backward passes while keeping exact binary codes during forward passes.

```python
class FlexLBPModule(nn.Module):
    def __init__(self, init_radius=1.5, learn_offsets=True, learn_thresholds=True):
        super().__init__()
        angles = [2.0 * np.pi * p / 8.0 for p in range(8)]
        init_offsets = [[init_radius * np.cos(a), init_radius * np.sin(a)] for a in angles]
        
        if learn_offsets:
            self.offsets = nn.Parameter(torch.tensor(init_offsets, dtype=torch.float32))
        else:
            self.register_buffer('offsets', torch.tensor(init_offsets, dtype=torch.float32))
            
        if learn_thresholds:
            self.thresholds = nn.Parameter(torch.zeros(8, dtype=torch.float32))
        else:
```

## What the numbers say

### Accuracy vs Loss and Paper Claims

In their original paper, Mohamed Alimoussa and Amal El Kaid (2026) report that FLEX-LBP improves nearest-neighbor accuracy over identical fixed descriptors by 3.55 points on average across six color texture benchmarks, gains 0.9 points with a linear discriminant readout, and gains 2.7 points with full end-to-end learning.

In our synthetic experiment, the main accuracy question must be answered with nuanced clarity:

- **Accuracy Impact:** On our 6-class synthetic dataset, fixed circular LBP ($R=1.0$ and $R=2.0$) already achieves 100.0% accuracy. Consequently, our experiment **does not demonstrate an accuracy improvement** over fixed descriptors due to ceiling saturation.
- **Loss and Confidence Impact:** Although accuracy saturates, backpropagating through exact binary codes via STE produces a dramatic reduction in cross-entropy loss. Fixed LBP ($R=1.0$) yields a test loss of 0.3873, and Fixed LBP ($R=2.0$) yields 0.2759. Learning offsets alone drops test loss to 0.1864, learning thresholds alone drops loss to 0.1044, and learning both simultaneously (FLEX-LBP Full) reduces loss to **0.0665**.

This 82.8% reduction in test loss (from 0.3873 to 0.0665) proves that gradient descent via STE successfully finds feature distributions that make class distributions far more linearly separable and confident.

### Geometric Interpretation of Learned Offsets

The initial sampling offsets form a symmetric circle of radius $R=1.5$ pixels. Upon optimization, the sampling points expand non-uniformly:

- Point $p_4$ stretches horizontally to $x = -4.3452$, extending the descriptor's receptive field to capture lower spatial frequencies.
- Point $p_2$ stretches vertically to $y = 3.5416$.
- Diagonal points $p_0, p_1, p_5, p_7$ expand outwards to radii between $3.3$ and $4.3$ pixels.

This asymmetric expansion allows the LBP operator to capture long-range directional correlations in the synthetic patterns (such as the horizontal, vertical, and diagonal sinusoidal gratings) that a tight circle of radius 1.5 pixels cannot span.

### Zero Overhead Deployment

One of the most practical properties of FLEX-LBP is its deployment efficiency. During training, sampling offsets are continuous values optimized via bilinear grid sampling. Once training is complete, the learned 2D offsets and 8 scalar thresholds are fixed. 

Inference latency for Fixed LBP is 0.155 ms per image, compared to 0.156 ms per image for FLEX-LBP Full. The difference of 0.001 ms is well within measurement noise. Because inference computes hard binary comparisons at the pre-computed grid locations, the deployed model achieves high feature quality with only 24 learned parameters and zero runtime penalty.

## What this experiment does not show

- **Real-World Texture Complexity:** The synthetic dataset consists of stylized mathematical patterns (sinusoids, checkerboards, Gaussian blobs, pink noise). Real-world textures (such as histological tissue samples, metallic surfaces, or terrain images) feature non-rigid deformations, complex illumination gradients, and intra-class scale variations where baseline fixed LBP accuracy is well below 100%.
- **Color Channel Interactions:** This implementation operates strictly on single-channel grayscale images ($48 \times 48$). The original paper evaluates color texture transforms across multiple spectral channels.
- **Nearest-Neighbor Classifiers:** We evaluated FLEX-LBP using a linear classifier head. We did not evaluate non-parametric $k$-nearest neighbor classification on raw histogram distances.

## Takeaways

1. **STE Enables Gradient Descent for Hard Binary Features:** Straight-Through Estimation successfully backpropagates gradients through exact binary step functions, allowing direct joint optimization of spatial offsets and decision thresholds.
2. **Drastic Loss Reduction at Zero Latency Cost:** On synthetic texture patterns, FLEX-LBP Full reduces test cross-entropy loss from 0.3873 to 0.0665 compared to fixed circular LBP ($R=1.0$), while adding only 24 parameters and maintaining an identical inference runtime (0.156 ms vs 0.155 ms per image).
3. **Data-Driven Geometry Beats Manual Tuning:** Learning spatial offsets allows sampling points to expand non-circularly (reaching radii up to 4.35 pixels) to match pattern scale and directionality.
